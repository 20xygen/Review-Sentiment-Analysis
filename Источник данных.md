# RuReviews

Sergey Smetanin и Michail Komarov, *Sentiment Analysis of Product Reviews in Russian using Convolutional Neural Networks*, 2019. [Репозиторий датасета](https://github.com/sismetanin/rureviews), [лицензия Apache 2.0](https://github.com/sismetanin/rureviews/blob/2f6e61d30dc6c58ba47dce72e5803e1f0a3f38a7/LICENSE).

Разметка тональности получена автоматически из оценок покупателей. Выборка составлена из отзывов на женскую одежду и аксессуары. Доли классов в ней нельзя переносить на поток отзывов сервиса.

Для ДЗ зафиксированы ID строк исходной версии. В учебных частях удалены пустые тексты, дубли после нормализации, конфликты меток и строки, похожие на контактные данные. Отзывы, показанные на семинарах, исключены из validation и test. Написание `neautral` в исходном файле исправлено на `neutral`.
